# System Patterns

## UI Testing:
- **UI Automator**: Used for black-box UI testing.
- **`testTag`**: Jetpack Compose `testTag` modifier is used to identify UI elements for testing. This maps to `contentDescription` in the accessibility tree, which UI Automator can then use with `By.desc()`.
